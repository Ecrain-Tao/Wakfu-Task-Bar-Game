# Animations des Chachas

Décompresser le pack PNG à la racine du dépôt. Les 64 fichiers sont rangés sous `assets/chachas/<variante>/<animation>/00.png`, etc.

Variantes : `noir`, `gribouille`, `roux`, `azur`.
Animations : `idle` (4 images), `walk` (6 images), `claw` (6 images).
Toutes les poses regardent vers la droite. Le jeu les sélectionne automatiquement si elles sont présentes ; sinon, il conserve le Chacha statique. La décompression doit préserver la structure des dossiers.
